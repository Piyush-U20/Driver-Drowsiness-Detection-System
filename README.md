# Driver Drowsiness Detection System
## Overview

The Driver Drowsiness Detection System is a real-time safety application developed to detect driver fatigue and reduce the risk of road accidents caused by drowsiness. The system monitors the driver’s eyes using computer vision techniques and generates alerts whenever signs of fatigue are detected.

The project is built using Python, Flask, OpenCV, MediaPipe, HTML, CSS, and JavaScript. It uses Eye Aspect Ratio (EAR) analysis for real-time eye monitoring and provides audio alerts, event logging, geolocation tracking, and map visualization.

Features
Real-time eye monitoring using webcam
Drowsiness detection using Eye Aspect Ratio (EAR)
Audio alarm and warning alerts
Live camera feed integration
Geolocation tracking
Event logging with timestamps
Map visualization for drowsiness events
Nearby rest-stop recommendation
Flask-based web interface
